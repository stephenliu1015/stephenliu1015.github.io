# ePortfolio Template

## 1. Fill in your content
Open `index.html` in any text editor (VS Code, Notepad, TextEdit).
- Search for `[` and replace every bracketed placeholder.
- Replace each yellow **"✎ Replace"** box (`<div class="todo">…</div>`) with your own paragraphs, wrapped in `<p>…</p>` tags.
- For the project reflection, write your 500–800 words as `<p>` paragraphs inside the "Reflection & Analysis" card. A word counter appears next to the heading.
- Update the name in the `<title>`, the brand link, the hero, and the footer.

## 2. Add your files to `assets/`
| File | What it is |
|---|---|
| `profile.jpg` | Professional headshot (square works best) |
| `resume.pdf` | Your résumé |
| `topic1-artifact.png` / `.pdf` | Topic 1 artifact |
| `topic3-artifact.png` | Topic 3 artifact |
| `project-figure.png`, `project-report.pdf` | Project showcase files |

If you rename a file, update its link in `index.html`. Every `<img>` needs a real `alt` description, which matters for accessibility.

## 3. Publish free on GitHub Pages
1. Create a free account at github.com.
2. Create a new **public** repository named `yourusername.github.io`.
3. Click **Add file → Upload files**, then drag in `index.html` and the `assets` folder. Click **Commit**.
4. Wait about 1 minute, then visit `https://yourusername.github.io`.

(Prefer Google Sites or Wix? You can copy the section structure and text from this template into those builders.)

## 4. Pre-submission checklist
- [ ] No yellow placeholder boxes or `[brackets]` left
- [ ] Every nav link, download, and image works (test in a private/incognito window)
- [ ] Checked on your phone
- [ ] Project reflection is 500–800 words
- [ ] Three learning reflections: growth, challenge, application
- [ ] Every source and image is cited in APA 7
- [ ] Link submitted to Canvas before 11:59 PM on the due date
